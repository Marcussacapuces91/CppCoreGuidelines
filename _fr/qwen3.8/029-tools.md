# <a name="s-tools"></a>Annexe D : Outils d'assistance

Cette section contient une liste d'outils qui soutiennent directement l'adoption des Lignes Directrices Essentielles de C++. Cette liste ne prétend pas être exhaustive des outils utiles à la rédaction de bon code C++. Si un outil est conçu spécifiquement pour soutenir et renvoie vers les Lignes Directrices Essentielles de C++, il est candidat à l'inclusion.

### <a name="St-clangtidy"></a>Outils : [Clang-tidy](https://clang.llvm.org/extra/clang-tidy/checks/list.html)

Clang-tidy dispose d'un ensemble de règles qui appliquent spécifiquement les Lignes Directrices Essentielles de C++. Ces règles suivent le schéma de nommage `cppcoreguidelines-*`.

### <a name="St-cppcorecheck"></a>Outils : [CppCoreCheck](https://docs.microsoft.com/en-us/visualstudio/code-quality/using-the-cpp-core-guidelines-checkers)

L'analyse de code C++ du compilateur Microsoft contient un ensemble de règles spécifiquement destinées à l'application des Lignes Directrices Essentielles de C++.
