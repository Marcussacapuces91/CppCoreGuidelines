# <a name="s-tools"></a>Annexe D : Outils de soutien

Cette section contient une liste d'outils qui soutiennent directement l'adoption des Directives de base C++. Cette liste n'a pas vocation à être exhaustive ; elle ne comprend que les outils utiles pour écrire un bon code C++ et qui sont explicitement conçus pour soutenir et référencer les Directives de base C++.

### <a name="St-clangtidy"></a>Outils : [Clang‑tidy](https://clang.llvm.org/extra/clang-tidy/checks/list.html)

Clang‑tidy propose un ensemble de règles qui appliquent spécifiquement les Directives de base C++. Ces règles portent le nom suivant : `cppcoreguidelines-*`.

### <a name="St-cppcorecheck"></a>Outils : [CppCoreCheck](https://docs.microsoft.com/en-us/visualstudio/code-quality/using-the-cpp-core-guidelines-checkers)

L'analyse de code C++ du compilateur Microsoft contient un ensemble de règles spécifiquement destinées à faire respecter les Directives de base C++.
