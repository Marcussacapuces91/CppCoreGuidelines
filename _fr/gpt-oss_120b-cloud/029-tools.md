# <a name="s-tools"></a>Annexe D : Outils de soutien  

Cette section présente une liste d’outils qui soutiennent directement l’adoption des **Lignes Directrices Essentielles de C++**. Cette liste n’a pas vocation à être exhaustive quant aux outils utiles pour écrire du bon code C++. Si un outil est conçu spécifiquement pour soutenir les Lignes Directrices et établit un lien avec celles‑ci, il constitue un candidat à l’inclusion.

### <a name="St-clangtidy"></a>Outils : [Clang-tidy](https://clang.llvm.org/extra/clang-tidy/checks/list.html)

Clang-tidy possède un ensemble de règles qui appliquent spécifiquement les Lignes Directrices Essentielles de C++. Ces règles sont nommées selon le schéma `cppcoreguidelines-*`.

### <a name="St-cppcorecheck"></a>Outils : [CppCoreCheck](https://docs.microsoft.com/en-us/visualstudio/code-quality/using-the-cpp-core-guidelines-checkers)

L’analyse de code C++ du compilateur Microsoft comprend un jeu de règles spécialement destinées à l’application des Lignes Directrices Essentielles de C++.
