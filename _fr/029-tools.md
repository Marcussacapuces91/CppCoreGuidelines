# <a name="s-tools"></a>Annexe D : Outils de soutien

Cette section contient une liste d’outils directement destinés à soutenir l’adoption des Directives Essentielles de C++. Elle n’a pas vocation à être exhaustive des outils utiles pour écrire du bon code C++. Si un outil est spécifiquement conçu pour soutenir et lié aux Directives Essentielles de C++ , il constitue un candidat à l’inclusion.

### <a name="St-clangtidy"></a>Outils : [Clang‑tidy](https://clang.llvm.org/extra/clang-tidy/checks/list.html)

Clang‑tidy possède un ensemble de règles qui appliquent explicitement les Directives Essentielles de C++. Ces règles portent le nom suivant : `cppcoreguidelines-*`.

### <a name="St-cppcorecheck"></a>Outils : [CppCoreCheck](https://docs.microsoft.com/en-us/visualstudio/code-quality/using-the-cpp-core-guidelines-checkers)

L’analyse de code C++ du compilateur Microsoft contient un ensemble de règles spécifiquement destinées à l’application des Directives Essentielles de C++.
